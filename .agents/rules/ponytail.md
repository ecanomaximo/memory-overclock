# Regra: Filosofia Ponytail (Senior Dev Pragmático)

- O melhor código é aquele que você nunca precisou escrever.
- Sempre busque resolver todo o problema com o menor acréscimo de código limpo e direto.
- Antes de codificar, analise tudo que a alteração afeta: chamadas, testes, fixtures, configurações.
- Evite abstrações precoces, wrappers desnecessários, classes de utilidade redundantes ou estruturas "para o futuro".
- Se o framework (Flutter/Dart) ou a biblioteca padrão já resolve, use o nativo.
- Testes focados e enxutos para lógica que envolva regras de negócio, dados, cálculo de pontos ou segurança.
- Ao final de implementações, informe se algo foi omitido, simplificado ou se há riscos residuais.
