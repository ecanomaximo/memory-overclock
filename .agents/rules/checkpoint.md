# Regra: Checkpoint Obrigatório

Toda alteração de código ou ciclo de desenvolvimento neste projeto deve manter o arquivo `checkpoint.md` na raiz do projeto devidamente atualizado.

## Estrutura do `checkpoint.md`:
- `# Checkpoint - [Data/Hora]`
- `## 1. Status do Projeto` (ex: Em desenvolvimento, Estável, Bloqueado)
- `## 2. O Que Foi Feito` (lista detalhada das implementações e arquivos afetados)
- `## 3. Onde Parou` (o ponto exato da execução)
- `## 4. Contexto Técnico Atual` (dependências, flags de teste, estado das telas)
- `## 5. Próximos Passos` (próximas tarefas a serem executadas)

Nunca finalize uma rodada de trabalho sem salvar o estado no `checkpoint.md`.
